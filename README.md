## 졸프 제출 버전 (2025-12-20)

### 1. 전처리 파이프라인 — `preprocessing/beauty_preprocess.ipynb`

Google Colab에서 작성한 30셀 노트북. 상품 메타와 리뷰를 정제해서, 추천에 바로 쓸 수 있는 상품 단위 점수 테이블을 만든다.

```
HF에서 로드 → 사전 필터 → 타입 정규화 → raw_text 통합·정제
→ 속성 온톨로지 + 규칙 추출 → 신뢰도 조정 → 리뷰 신호 계산 → 조인 → CSV 출력
```

| 단계 | 결과 (노트북 출력 기준) |
|---|---|
| 원본 규모 | 메타 112,590개 / 리뷰 701,528건 |
| 사용 범위 | 메타 앞 15,045개 / 리뷰 앞 12,358건 (Colab 메모리 때문에 앞에서부터 자름) |
| 사전 필터 | 15,045 → 11,307개 (3,738개, 24.8% 제거) |
| 속성 추출 | brand, product_type, target_audience, volume_ml, scent, price_num 6개 정의 |
| target_audience 개선 | hard pass 10.6% → 17.8% (1,200 → 2,007개) |
| 최종 출력 | `beauty_item_scoring_all.csv` 11,307행 |

#### 전처리 판단 근거

| 판단 | 이유 | 구현 |
|---|---|---|
| 허용/차단 키워드 사전 필터 | All_Beauty에 문신 장비·공구처럼 뷰티 추천 대상이 아닌 품목이 섞여 있음 (제거 예: 문신 기계용 플런저 바) | 허용어 1개 이상 포함 AND 차단어(tattoo, cartridge, needle 등) 미포함 |
| 가죽 컨디셔너 맥락 규칙 | "conditioner"가 헤어 제품과 가죽 관리 제품 양쪽에 쓰임 | "leather conditioner"가 있고 hair/scalp 맥락이 없으면 제외 **(제출본에서는 적용 안 됨, 아래 한계 참고)** |
| 출처별 가중치 | 구조화된 필드일수록 값이 정확함 | details 1.00 > feature 0.85 > title 0.75 > description 0.60 |
| 속성별 hard 임계값 | 속성마다 오추출 위험이 다름 | brand 0.80, product_type 0.75, target_audience 0.70, scent 0.75, volume_ml 0.65, price_num 0.90 |
| 합의 보너스 | 여러 출처에서 같은 값이 나오면 신뢰도가 높음 | 2개 출처 +0.15, 3개 이상 +0.20 (상한 1.0) |
| details 직접 파싱 + fallback | 본문 키워드만으로는 target_audience를 거의 못 잡음 | details의 Skin Type / Hair Type 등 키를 직접 읽음 → hard pass 10.6% → 17.8% |
| 리뷰 신호 보정 | 리뷰 1~2건짜리 상품이 평균 별점 정렬을 왜곡함 | 베이즈 평균(α=10, μ=4.081), 윌슨 하한(95%, 별점 4 이상을 긍정), log1p 인기도, 도움됨, 데이터 내부 상대 최신성을 0.50 / 0.20 / 0.15 / 0.10 / 0.05로 가중합 |

### 2. 추천 앱 — `app/app_sparse_final.py` (팀원 작업)

상품 × 속성 감성 희소행렬로 코사인 유사도 추천을 하는 Streamlit 앱.

```
기준 상품 선택 → 속성 감성값 수정·추가·삭제 → L2 정규화 → 코사인 유사도 top-K → CSV 다운로드
```

- 입력 행렬: 50,000 상품 × 9,976 속성, 값이 있는 칸 426,145개 (상품당 평균 8.5개), 값 범위 -0.99 ~ 1.00
- 행렬은 팀원이 spaCy(구문 분석)와 VADER(감성 점수)로 만들었다. **생성 코드는 이 레포에 없다.**

## 알려진 한계 (제출 버전)

제출 이후 다시 검토하면서 찾은 문제다. 수치는 모두 제출본 노트북에 찍힌 출력이나 입력 파일에서 직접 확인했다.

**전처리**

- **리뷰가 대부분 연결되지 않았다.** 메타와 리뷰를 각각 앞에서부터 잘라서, 리뷰 12,358건 중 남은 상품에 연결된 것은 1,424건이다. 리뷰가 있는 상품은 967개(8.6%)다. 출력의 "review_signal 커버리지 100%"는 리뷰 없는 상품을 0으로 채운 결과다.
- **6개 속성 중 2개가 최종 CSV에서 비어 있다.** brand는 11,307개 전부 Unknown이고 volume_ml은 0%다. price_num은 18.3%(2,072개)만 채워졌다.
- **가죽 컨디셔너 규칙이 적용되지 않았다.** Cell 4에서 `keep_mask`를 다시 계산했지만 `meta_df`에 다시 적용하지 않았다. 같은 셀에서 차단어에 추가한 "leather" 등도 차단 판정이 끝난 뒤라 효과가 없다. 그래서 "Howard LC0008 Leather Conditioner"(B01CUPMQZE)가 최종 CSV에 남아 있다.
- **키워드를 부분 문자열로 비교한다.** 차단어 "vice"가 "device", "service"에도 걸리고 허용어 "oil"이 "toilet"에도 걸린다. 이 때문에 잘못 제거되거나 남은 상품이 몇 개인지는 재실행해서 확인할 예정이다.
- 카테고리 문자열이 비어 있어 카테고리 기반 허용 규칙은 한 번도 걸리지 않았다(0.0%). 필터는 텍스트 매칭으로만 동작했다.
- Colab 전용 경로(`/content/`)를 쓰고, 셀 실행 순서에 의존한다.

**추천 앱**

- 속성 9,976개 중 2,561개는 값이 하나도 없는 열이다.
- 상위 속성을 일반어가 차지한다(party가 8,790개 상품에 등장, 그다음 cake, ingredient, topper, birthday 순). 숫자 섞인 속성("100ml", "1st", "00" 등)은 544개지만 전체 값의 0.21%이고, 추천 속성 목록 상위 150개에는 없다.
- 사이드바에 디버그용 디렉터리 목록 출력이 남아 있다.
